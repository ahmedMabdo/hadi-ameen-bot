1- The first part for calling the restaurant with a pre-recorded message you can use the following API:
curl --location 'https://ivr-test-poc-api.aswat.co/integrations/cti/click2audio/<will be called number>' \
--header 'api_key: <api_key>' \
--form 'storageName="<file_hash_name>"' \
--form 'scheduleAt=""' \
--form 'timeout="60"' \
--form 'callerIDNumber="<caller_DID>"'

B- The second solution is to set up a workflow — a low-code solution inside ZIWO — that can filter calls and post only the relevant ones to your API. Specifically, it will filter outbound calls made from a specific DID “ZIWO DID” (used for restaurant notifications), and then POST the call results to your API accordingly.
This module is with extra charge “setup fees and running cost with 0.01$ per each outbound call”. With minimum commitment 29$/mont.

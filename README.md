# هادي أمين — إعداد الربط بـ Azure DevOps

الملف ده بيشرح خطوات تفعيل ربط هادي بـ ADO قبل/عند الرفع على السيرفر.

## إيه اللي اتعمل

- **`CLAUDE.md`** — اتحدّث: أضيف أقسام (الربط بـ ADO، رفع CR/Customer Issue من ديسكورد، أسئلة السبرنت والذاكرة، أمثلة محادثة، حدود أمان).
- **`knowledge/sprints.md`** — ملف ذاكرة السبرنتات (MS-91 / MS-92 + السيكونات + الإجازات + قالب + سجل أسئلة).
- **`setup/`** — قوالب الإعداد (محتاجة تتنسخ لأماكنها لأن ملفات الإعداد المخفية محمية من التعديل المباشر).

## خطوات التفعيل (مرة واحدة)

> ملاحظة: الملفات المخفية (`.mcp.json` / `.env` / `.gitignore` / `.claude/settings.local.json`) محمية، فالقوالب اتحطّت في `setup/` وانت بتنقلها.

1. **MCP**: انسخ محتوى `setup/mcp.json` لملف اسمه `.mcp.json` في جذر المشروع.
2. **الأسرار**: انسخ `setup/env.example` لملف `.env` في الجذر، واملا `AZURE_DEVOPS_PAT` بالتوكن الحقيقي.
3. **gitignore**: ضيف سطور `setup/gitignore.txt` لملف `.gitignore` — **مهم جداً عشان `.env` ما يترفعش**.
4. **الصلاحيات**: استبدل محتوى `.claude/settings.local.json` بمحتوى `setup/settings.local.json` (بيضيف أدوات ADO ويمنع التعديل/الحذف).
5. شغّل البوت وجرّب الأوامر تحت.

## الصلاحيات المضبوطة

- **قراءة**: كل بوردات `0_Projects_Team` (تذاكر، سبرنت، iterations).
- **كتابة محدودة**: إنشاء Work Item + إضافة Comment فقط.
- **ممنوع**: تعديل (`wit_update_work_item`) أو حذف — متمنوعين صراحةً في `deny`.

## تأكيد المصادقة (مهم)

خادم `@azure-devops/mcp` الرسمي بيدعم أكتر من طريقة مصادقة. لو ما اتصلش بالـ PAT من `.env` على السيرفر، الحلول البديلة:
- استخدام `az login` على السيرفر (DefaultAzureCredential)، أو
- التأكد من اسم متغير الـ PAT اللي الإصدار المتسطّب بيقراه.

> ده النقطة الوحيدة اللي محتاجة **اختبار فعلي عند التشغيل** — باقي الإعداد جاهز.

## أوامر تجربة على ديسكورد

- "هادي في كام issue مفتوح في السبورت؟" → قراءة.
- "هادي اعملي CR إن شاشة المنتجات تبقى أسرع" → بيجمع التفاصيل، يأكّد، يرفع، يرجّع لينك.
- (مع سبرنت جديد) هادي يسأل آسر عن المواعيد الناقصة ويحفظها في `knowledge/sprints.md`.

## أمان

- التوكن اللي اتشارك في الشات لازم يتعمله **rotate**.
- `.env` لازم يكون في `.gitignore` ومايترفعش أبداً.
